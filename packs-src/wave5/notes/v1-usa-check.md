# v1-usa check (wave 5, independent fact-check)

Checked all 246 clues in n1, n2, e1, e2, nf and ef. For every clue I also pulled every deployed clue
(original, easy, campaign) with the same response, plus a keyword grep on the clue's key fact, and
replaced any fact an existing clue already states in other words. Both checkers print OK on all six files;
check-new-clues on the whole drafts folder names none of these files.
